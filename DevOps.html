🎯 Objectifs du Projet

Les piliers de notre démarche DevOps

🧪

Application testée

Développement d'une API Node.js/Express avec des tests unitaires Jest & Supertest couvrant 100% des endpoints.

🐳

Conteneurisation optimisée

Images Docker minimalistes (Alpine, multi-stage build) réduisant la taille de 900 Mo à ~100 Mo.

⚡

Pipeline automatisé

GitHub Actions déclenche tests + build + push Docker Hub à chaque commit, en moins de 2 minutes.

📦

Portabilité totale

Application exécutable partout grâce à Docker Compose : un simple docker compose up suffit.

Déploiement

1. Push du code sur GitHub

Le développeur pousse ses modifications. Le pipeline se déclenche automatiquement.

2. Exécution des tests unitaires

Jest & Supertest valident l'intégrité de l'API avant toute construction.

3. Build de l'image Docker

Construction multi-étapes avec injection des métadonnées (commit, date, version).

4. Push vers Docker Hub

L'image est publiée sur le registre, prête à être déployée n'importe où.

5. Déploiement automatique

Le serveur récupère la dernière image et la met en production (Docker Compose).

⚙️ Détails de l'Implémentation

Structure du projet, Dockerfile et pipeline GitHub Actions

📁 Structure du Projet

# Organisation professionnelle
├── src/              # Code source (routes, contrôleurs, services)
├── tests/            # Suites de tests Jest + Supertest
├── .github/workflows/ # Pipeline CI/CD (main.yml)
├── Dockerfile        # Build multi-stage optimisé
└── docker-compose.yml # Déploiement local simplifié

🐳 Dockerfile – Build Multi-Stage

# Stage 1: Build
FROM node:20-alpine AS builder
WORKDIR /app
COPY . .
RUN npm install && npm test

# Stage 2: Production (image finale ~100 Mo)
FROM node:20-alpine
WORKDIR /app
COPY --from=builder /app/src ./src
RUN npm install --omit=dev
CMD ["node", "src/server.js"]

🔧 Pipeline GitHub Actions (main.yml)

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install
      - run: npm test
      - name: Build Docker Image
        run: docker build -t my-app .
